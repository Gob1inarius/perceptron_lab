# Перцептрон

Лабораторная работа по курсу «Программирование на Python». 

Выполнил студент группы 25КНТ-6 Шишков Владислав.

Программа представляет собой однослойный перцептрон для бинарной классификации. Она генерирует данные (два облака точек или набор iris), обучает перцептрон, печатает точность и по желанию строит графики: границу решения и число ошибок по эпохам.

## Запуск

Нужен [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run python -m perceptron.cli --samples 200 --lr 0.1 --epochs 50
```

Результат: `Accuracy: 1.00`.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--samples` | 200 | число точек в синтетическом наборе (не меньше 2); для `iris` игнорируется |
| `--lr` | 0.1 | скорость обучения (больше 0) |
| `--epochs` | 50 | число эпох обучения (не меньше 1) |
| `--dataset` | `clouds` | набор данных: `clouds` (два облака точек) или `iris` |
| `--plot` | выкл. | построить графики, сохранить их в `boundary.png` и `errors.png` и показать на экране |

При неверных значениях параметров программа печатает короткое сообщение об ошибке и подсказку по запуску.

Пример с iris и графиками:

```
uv run python -m perceptron.cli --dataset iris --plot
```
